# Archive

These files are historical working notes from forge-ui's development: early architecture drafts, audit reports, implementation summaries, status checklists and design specs. They are kept for reference only.

**They do not describe the released product.** Status lines such as "complete" or "production ready", feature lists, counts and plans in these files reflect what the authors expected at the time, not what forge-ui ships. For what forge-ui does today, read the [README](../../README.md) and the current docs in [docs/](../README.md).

| Folder | Contents |
|---|---|
| `architecture-v3-early/` | Early v3 architecture and analysis notes |
| `reports-2026-02/` | February 2026 audit and quality reports |
| `specs-marketplace-draft/` | A draft marketplace spec that was not built |
| `working-notes-2026/` | Status reports, readiness checklists, implementation summaries, dogfooding notes and design specs moved out of `docs/` in November 2026 |
